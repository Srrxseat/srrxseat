# Pine Script indicators

สคริปต์สำหรับใช้ใน TradingView (Pine Script v6)

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `ema-multi.pine` | EMA 7/30/50/100/200 + Price Imbalance (FVG) แบบแท่งสั้น ไม่ลากยาว พร้อม diamond marker สำหรับ back testing, ตารางสรุป และ alert 8 แบบ |
| `ema-multi-pantone.pine` | ตัวเดียวกันทุกฟีเจอร์ เปลี่ยนแค่ **สี default เป็นชุด Pantone** ชื่อสคริปต์ต่างกัน จึง add พร้อมกันบนกราฟเดียวได้ |

## วิธีติดตั้ง

1. เปิดกราฟใน TradingView (เว็บหรือแอปเดสก์ท็อป — มือถือเขียนไม่ได้)
2. เปิดแถบล่างของกราฟ แล้วเลือกแท็บ **Pine Editor**
3. ลบโค้ดตัวอย่างทิ้ง วางเนื้อหาไฟล์ `.pine` ลงไปทั้งหมด
4. กด **Save** ตั้งชื่อสคริปต์ → กด **Add to chart**
5. เรียกใช้ครั้งถัดไปที่ปุ่ม **Indicators → My scripts**

## กลุ่มการตั้งค่าใน `ema-multi.pine`

- **ทั่วไป** — แหล่งราคา, ล็อก timeframe, ความหนาเส้น, ป้ายชื่อ + ระยะห่างป้าย, ตารางสรุป
  - สวิตช์ **ล็อก Timeframe ของ EMA** ปิดไว้เป็นค่าเริ่มต้น = EMA คำนวณบน TF ของกราฟเสมอ ขยับตามทุกครั้งที่สลับ TF (ช่อง TF ด้านล่างจะมีค่าค้างอยู่ก็ไม่มีผล)
  - เปิดสวิตช์ + เลือก TF ในช่องถัดมา = ล็อก EMA ไว้ที่ TF นั้นโดยตั้งใจ (เช่นดู EMA รายสัปดาห์บนกราฟ 4H) จะมีป้าย ⚠ เตือนบนกราฟ
  - **แถวล่างสุดของตารางสรุป** บอก TF ของกราฟ และบอกว่า EMA "ตามกราฟ" (เขียว) หรือ "ล็อก" (ส้ม) อยู่ — ใช้เช็คได้ทันทีว่ารันโค้ดเวอร์ชันล่าสุดและตั้งค่าถูกไหม
- **ความโปร่งใส** — 0 = ทึบ, 100 = ใส แยกได้ 6 จุด: โซนแนวโน้มขาขึ้น, โซนแนวโน้มขาลง, แท่ง Imbalance, ขอบแท่ง, พื้นหลังตาราง, พื้นหลังป้ายชื่อ — โซนขาขึ้น/ขาลงมี **checkbox ปิดแยกฝั่ง** ได้ด้วย
- **เส้น EMA** — ค่าเริ่มต้น 7 / 30 / 50 / 100 / 200 + เส้นสำรอง 1 เส้น (ปิดไว้, ค่าเริ่มต้น 400) แต่ละบรรทัดมี เปิด-ปิด / ความยาว / สี พร้อมเลือกสีโซนขาขึ้น-ขาลงที่ระบายระหว่าง EMA เร็ว-ช้า
- **Price Imbalance** — ช่องว่างแบบ 3 แท่ง (low > high[2] = ฝั่งซื้อ, high < low[2] = ฝั่งขาย)
  - **รูปแบบการแสดง 3 แบบ**
    - `ระบายสีแท่งเทียน` (ค่าเริ่มต้น) — ระบายทั้งแท่งเทียนเป็นสีที่เลือก
    - `ระบายเฉพาะช่วงช่องว่าง` — ระบายแค่ช่วงราคาที่เป็นช่องว่างจริง (จาก high แท่งแรก ถึง low แท่งที่สาม)
    - `กล่อง` — กล่องสั้นแบบเดิม ปรับความกว้าง 1 หรือ 3 แท่งได้
  - **ตำแหน่งที่ระบาย** คุมด้วยช่องเดียวทุกโหมด (รวม diamond): `-2` = แท่งแรกของแพทเทิร์น, `-1` = แท่งกลาง, `0` = แท่งที่ยืนยันช่องว่าง, `1` ขึ้นไป = เยื้องไปทางขวา (ค่าเริ่มต้น 1)
  - สีปรับได้ 3 ค่า: ฝั่งซื้อ, ฝั่งขาย, และสีเมื่อถูกเติมเต็มแล้ว + เปิด-ปิดขอบแท่ง
  - กรองขนาดขั้นต่ำได้ทั้งแบบ % ของราคา และแบบเท่าของ ATR14 (0 = ไม่กรอง)
  - เงื่อนไข "เติมเต็ม" 3 แบบ: แตะขอบใกล้ / แตะขอบไกล / ปิดแท่งผ่าน — เมื่อเติมเต็มแล้วจะเปลี่ยนเป็นสีจาง หรือเลือกให้ลบทิ้งก็ได้
  - จำกัดจำนวนแท่งที่เก็บ (ค่าเริ่มต้น 100), ซ่อนแท่งที่เกิดมานานกว่า N แท่ง, เส้นกลาง 50%
- **Diamond (Back Testing)** — เปิด-ปิด, สีแยกฝั่งซื้อ/ขาย, ขนาดเล็ก/ใหญ่ ตำแหน่งตรงกับที่ระบายสี สำหรับไล่ดูย้อนหลังว่าสัญญาณเกิดที่ไหน

> หมายเหตุเรื่องลิมิต: TradingView จำกัด 64 plot ต่อสคริปต์ และการส่ง "สี" เป็น series ก็ถูกนับเป็น plot ด้วย จึงรวม plot ฝั่งซื้อ/ขายเข้าเป็นชุดเดียวแล้วเลือกสีตามทิศทาง ถ้าจะเพิ่มเส้นหรือ marker ใหม่ ให้เผื่อโควตานี้ไว้

## เคล็ดลับการแสดงผล

- แถบชื่อ indicator บนกราฟจะโชว์ค่า input ทั้งหมดต่อกันยาวๆ — ปิดได้ที่ คลิกขวาบนกราฟ → **Settings → Status line** → เอาติ๊ก **Indicator arguments** ออก
- ถ้าป้ายชื่อ EMA ทับกันตอนเส้นบีบเข้าหากัน ให้เพิ่มค่า **ระยะห่างป้ายชื่อ** ในกลุ่ม "ทั่วไป" (ค่าเริ่มต้น 4 แท่ง) หรือใส่ 0 ให้เรียงตรงกัน
- บน TF ใหญ่ (1W/1M) ช่องว่างมีเยอะ แนะนำใส่ **ขนาดขั้นต่ำ** เป็น ATR 0.5–1 เท่า เพื่อกรองช่องว่างจิ๋วออก

## ตั้ง Alert

คลิกขวาบนกราฟ → **Add alert** → ช่อง Condition เลือกชื่อ indicator แล้วเลือกเงื่อนไข
(EMA 7 ตัด 30 ขึ้น/ลง, Golden/Death Cross 50-200, ราคายืนเหนือ/หลุด EMA 200, Imbalance ฝั่งซื้อ/ขายใหม่)

## ชุดสี Pantone (`ema-multi-pantone.pine`)

ค่า hex เป็นค่าเทียบเคียงสำหรับจอ ไม่ใช่ค่าพิมพ์จริง (Pantone เป็นระบบสีสำหรับงานพิมพ์ — สีบนจอเทียบได้ใกล้เคียงเท่านั้น) ทุกค่ายังแก้เองได้จากหน้า Settings ตามเดิม
