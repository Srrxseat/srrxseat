# Pine Script indicators

สคริปต์สำหรับใช้ใน TradingView (Pine Script v6)

| ไฟล์ | คำอธิบาย |
| --- | --- |
| `ema-multi.pine` | EMA 6 เส้น (7/14/25/50/100/200) + Price Imbalance (FVG) ในตัวเดียว ปรับความยาว/สี/เปิด-ปิดได้, ระบายโซนแนวโน้ม, ป้ายชื่อท้ายเส้น, ตารางสรุป, ปรับความโปร่งใสได้ทุกพื้นหลัง, alert 8 แบบ |

## กลุ่มการตั้งค่าใน `ema-multi.pine`

- **ทั่วไป** — แหล่งราคา, ล็อก timeframe (ดู EMA ของ TF ใหญ่บนกราฟเล็ก), ความหนาเส้น, เปิด-ปิดป้ายชื่อ/ตารางสรุป
- **ความโปร่งใส** — 0 = ทึบ, 100 = ใส แยกค่าได้ 5 จุด: โซนแนวโน้มระหว่าง EMA, กล่อง Imbalance, ขอบกล่อง Imbalance, พื้นหลังตาราง, พื้นหลังป้ายชื่อ
- **เส้น EMA** — 6 บรรทัด แต่ละบรรทัดมี เปิด-ปิด / ความยาว / สี
- **Price Imbalance (FVG)** — ช่องว่างแบบ 3 แท่ง (low > high[2] = ฝั่งซื้อ, high < low[2] = ฝั่งขาย)
  - กรองขนาดขั้นต่ำได้ทั้งแบบ % ของราคา และแบบเท่าของ ATR14 (ใส่ 0 = ไม่กรอง)
  - เลือกเงื่อนไข "เติมเต็ม" ได้ 3 แบบ: แตะขอบใกล้ / แตะขอบไกล / ปิดแท่งผ่าน
  - เลือกได้ว่าจะลบกล่องที่เติมเต็มแล้ว หรือเก็บไว้เป็นสีเทา, จำกัดจำนวนกล่อง, ยืดกล่องไปข้างหน้า, เส้นกลาง 50%

## วิธีติดตั้ง

1. เปิดกราฟใน TradingView (เว็บหรือแอปเดสก์ท็อป — มือถือเขียนไม่ได้)
2. เปิดแถบล่างของกราฟ แล้วเลือกแท็บ **Pine Editor**
3. ลบโค้ดตัวอย่างทิ้ง วางเนื้อหาไฟล์ `.pine` ลงไปทั้งหมด
4. กด **Save** ตั้งชื่อสคริปต์ → กด **Add to chart**
5. เรียกใช้ครั้งถัดไปที่ปุ่ม **Indicators → My scripts**

## ตั้ง Alert

คลิกขวาบนกราฟ → **Add alert** → ช่อง Condition เลือกชื่อ indicator แล้วเลือกเงื่อนไข
(EMA เร็วตัดขึ้น/ตัดลง, Golden Cross, Death Cross, ราคายืนเหนือ/หลุด EMA 200, Imbalance ฝั่งซื้อ/ขายใหม่)
